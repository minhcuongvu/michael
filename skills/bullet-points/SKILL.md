Prefix every line with `>`, `>>` for sub-points. One short sentence per line; lowercase fine. Use when the user wants scannable, no-fluff answers.

Keep code blocks, file contents, error messages, and direct quotes in original formatting.

```
> **main idea** is this thing
>> supporting detail
> **file**: `path/to/file.ts:123` — found the issue
```
